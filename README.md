# Financial Records & Reporting System

A Python + MySQL based financial backend system that manages accounts, transactions, and budgets, and generates real-time financial reports.

## Features
- Account Management (CRUD)
- Transaction Management
- Budget Planning
- Budget vs Actual Reporting
- SQL Joins and Aggregation
- Flask-based Web Interface

## Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS
- SQL

## Setup
1. Run schema.sql in MySQL
2. Install requirements:
   pip install -r requirements.txt
3. Update db.py with your DB credentials
4. Run:
   python app.py
